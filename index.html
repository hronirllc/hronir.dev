What we do

Hronir LLC is an independent software studio. We design and build native applications for Apple platforms and the web — small, fast, carefully made tools that do one thing properly.

We work on a small number of projects at a time, from first sketch through release and the long maintenance tail that follows it. Some of that work is our own; some is built for other people.

  • Application development

    Native iOS, iPadOS, and macOS applications written in Swift, built to current platform conventions and submitted through the App Store.

  • Web & services

    Web front ends, APIs, and the backend infrastructure that keeps them running — designed to stay small and be cheap to operate.

  • Product & interface design

    Interaction and interface design carried through implementation, so what ships resembles what was drawn.

Approach

Software tends to accumulate. We would rather it didn't. Our preference is for fewer dependencies, smaller binaries, plainer data formats, and interfaces that can be understood without a tour.

The name comes from Borges — an hrön is a duplicated object, a thing that exists because someone expected to find it. It seemed like a reasonable description of what software is.
